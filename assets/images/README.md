# Images — B_gadget

Folder ini untuk asset gambar.

- `logo.svg` → logo ◈ B_gadget (hitam elegan)
- `nota-qr.png` → QR tracking nota (generate backend nanti)
- `foto-kondisi/` → foto before/after HP (akan di-upload via API)

Saat ini gambar pakai CDN `i.pravatar.cc` untuk avatar teknisi. Ganti dengan file lokal jika offline:
```
frontend/assets/images/avatar-andi.jpg
frontend/assets/images/avatar-sinta.jpg
frontend/assets/images/avatar-budi.jpg
```

Contoh logo SVG sudah ada di `frontend/assets/images/logo.svg`.
